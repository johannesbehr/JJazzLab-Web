About this diagnostic

This page is a static client. It does not need to be installed on the Render Server itself and can test a remote instance.

If the page is hosted on a different domain, the target server must allow this page's origin through its CORS configuration.

The initial API accepts a song file only. Style selection, mix configuration and additional render options are not part of this first implementation.
