# SoundFonts

Place the approved `.sf2` or `.sf3` file in this directory before publishing.

The deployed URL will be:

`https://<github-pages-host>/<repository>/player/soundfonts/<filename>`

Pass the complete URL using the required `soundfont-url attribute. The host must allow cross-origin fetch requests from embedding pages.

The JJazzLab SoundFont binary is not included in this source commit; add it before publishing the player.
